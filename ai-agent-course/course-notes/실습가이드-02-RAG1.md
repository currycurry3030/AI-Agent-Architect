# 실습 가이드 2 · RAG 1 — 저장과 검색 5단계 직접 관찰

목표: RAG 5단계(파싱·청킹·임베딩·검색·생성)를 눈으로 확인하고, BM25·하이브리드 검색을 직접 붙여본다.

원본은 [학습노트 02](02-RAG1-저장과검색.md) 참고. 원본은 배부된 `rag-lab.zip`(완성 앱)을 풀어서 시작하지만, 자습에서는 **Claude Code에게 동등한 앱을 직접 만들게** 합니다 — 오히려 "이미 만들어진 앱 파악하기"가 아니라 "요구사항으로 앱 만들기" 연습이 한 번 더 됩니다.

### 2. naive RAG 단계별 관찰
- [ ] PDF 3~5개를 하나씩 업로드 → ① 탭에서 페이지별 추출 글자 수 확인, 빨간 칸(추출 실패 페이지) 있으면 원문과 대조
- [ ] ② 탭에서 같은 문서를 3가지 청킹 기준으로 각각 미리보기 → 청크 개수·길이 비교, 문장이 중간에서 끊긴 조각 찾아보기
- [ ] ③ 탭에서 [적재] — 문서 전부 적재, 청크 수 확인
- [ ] ④ 탭에서 문서 내용에 대한 질문을 한국어로/영어로(문서가 영어라면) 각각 던져 비교
- [ ] [답변 생성] 켜고 같은 질문 재실행 → 답변과 근거 청크 대조
- [ ] 문서에 없는 내용을 일부러 질문 → 환각 여부 확인
- [ ] 표나 그림 관련 내용을 질문 → 파싱에서 누락됐는지 확인

### 3. BM25 + 하이브리드 검색 추가
```
이 앱의 검색 화면에 BM25(키워드) 검색을 추가해줘.
검색 화면에서 의미 검색과 BM25 검색 결과를 좌우로 나란히 볼 수 있게 구현해줘.
```
(서버 재시작 후) 단어만 넣어 테스트: 문서에 나오는 고유명사, 숫자·기호가 섞인 표현, 오타 등

```
의미 검색과 BM25 의 결과를 하나로 합치는 하이브리드 검색을 추가해 줘.
점수를 그대로 더하지 말고 순위로 결합해 줘.
검색 화면에 [의미 검색] [BM25] [하이브리드] 세 열을 나란히 보여 줘.
```

### 4. 문서 추가 후 재질문
- [ ] 판(버전)이나 항목명이 비슷한 문서를 하나 더 적재 (또는 같은 문서의 개정판이 있다면 함께)
- [ ] 애매하게 겹칠 만한 질문을 던져 답변·근거 5개의 출처를 기록해두기 → **이 기록이 3교시(실습 가이드 3)의 출발점**
