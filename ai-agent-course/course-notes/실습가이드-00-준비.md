# 자습·실습 가이드 — 준비

이 가이드는 [학습노트(01~08)](README.md)의 **개념 설명을 압축하고, 혼자서 순서대로 따라 할 수 있는 체크리스트**로 재구성한 것입니다. 개념이 궁금하면 학습노트를, "지금 뭘 해야 하지?"는 이 가이드를 보세요.

## 원본 교육과 다른 점 (자습 시 꼭 확인)

원본은 하루짜리 **사내 교육**이라 배부 계정·배부 파일·팀 제출 플랫폼에 의존합니다. 혼자 할 때는 아래를 대체합니다.

| 원본(교육) | 자습 대체 |
|---|---|
| 배부된 OpenAI API Key | **본인 OpenAI API 키** 발급 (platform.openai.com → API keys). 결제수단 등록 필요, 사용량 한도(Usage limits)를 낮게 걸어두는 걸 권장 |
| 모델명 `gpt-5.6-luna` (교육 시점 배부 계정에 연결된 별칭) | 본인 계정에서 **실제 사용 가능한 최신 GPT 모델**로 대체 (Claude Code에게 "지금 내 OpenAI 계정에서 쓸 수 있는 모델 목록을 확인해줘"라고 물어보면 됨) |
| 배부 zip (`rag-lab.zip`, `agents-lab.zip`) — 미리 만들어진 실습용 앱 | **02·04 가이드에 포함된 부트스트랩 프롬프트**로 Claude Code가 동등한 앱을 직접 만들어줌 (오히려 바이브코딩 연습이 한 번 더 되는 셈) |

| 트랙2 문서 「2026년 6월 소비자물가동향」 | **실제 공공 자료라 그대로 다운로드 가능**: [국가데이터처(통계청) 소비자물가동향](https://kostat.go.kr) 최신 호를 내려받아 사용 |

## 환경 준비 체크리스트

- [ ] PowerShell에서 Claude Code 설치 확인
  ```powershell
  claude --version
  ```
  안 되면: `irm https://claude.ai/install.ps1 | iex` 실행 후 터미널 재시작
- [ ] OpenAI API 키 발급 — https://platform.openai.com/api-keys → `sk-...`로 시작하는 키 복사
- [ ] (선택, 5교시용) Tavily 무료 API 키 발급 — https://app.tavily.com (구글 계정 가입 가능)
- [ ] 실습 루트 폴더 생성
  ```powershell
  mkdir C:\ai-agent-selfstudy
  cd C:\ai-agent-selfstudy
  ```
- [ ] 세션별 하위 폴더는 각 실습 가이드 안내에 따라 그때그때 생성 (`01-webapp`, `02-rag-lab`, `04-agent-lab`, `07-capstone` 등)

## 진행 순서

```
00 준비 (지금 여기)
 └ 01 웹앱      → 02 RAG1 → 03 RAG2 (같은 폴더 이어서)
                → 04 ToolCalling → 05 MCP → 06 MultiAgent (같은 폴더 이어서)
                → 07 캡스톤 (자유 주제, 나만의 프로젝트)
```

01은 독립적인 폴더, 02~03은 같은 `rag-lab` 폴더를 이어서 사용, 04~06은 같은 `agent-lab` 폴더를 이어서 사용합니다. 07은 앞의 것들 중 하나를 골라 본인 주제로 확장합니다.

## 각 세션 진행 방식 (공통)

1. 실습 가이드의 체크박스를 위에서부터 순서대로 실행
2. 코드가 바뀌는 지시를 내린 뒤에는 **서버를 재시작**해야 반영됨 (검은 창 `Ctrl+C` → 재실행)
3. 막히면 각 가이드의 "막히면" 표를 먼저 확인, 그래도 안 되면 Claude Code에게 오류 메시지를 그대로 붙여넣고 물어보기
4. 개념이 헷갈리면 같은 번호의 [학습노트](README.md)를 열어 배경 설명 확인

준비가 끝났으면 [01-웹앱 실습 가이드](실습가이드-01-웹앱.md)로 이동하세요.
