# 8교시 · 캡스톤 2 — 완성과 제출

## 결과 페이지 = 단일 HTML 파일 하나
제출 플랫폼은 **HTML 파일 한 개만** 받는다 (GitHub 주소·압축파일 불가). CSS/JS는 파일 안에, 이미지는 base64로 인라인, 화면 시연은 자바스크립트 mock-up으로 구현.

### 지시문 (그대로 복사해서 사용)
```
프로젝트가 완성됐어. 제출용 결과 페이지 report.html을 만들어줘.
작업 제한 시간은 5분이야. 아래 순서와 상한을 지키고, 완성 후 다듬는 작업은 하지 마.

[작업 순서]
1. report.html 본문을 먼저 쓴다. 스크린샷이 들어갈 자리는 <!--IMG:파일명--> 주석만 남긴다.
2. 작업 폴더의 캡처 파일(png/jpg, 최대 5장)을 base64로 바꿔 그 자리에 <img>로 넣는
   짧은 파이썬 스크립트를 만들어 실행한다.
   - base64 문자열을 네가 직접 쓰거나 파일에 타이핑하지 마. 반드시 스크립트로 넣어.
   - 이미지 파일을 열어서 보지 마. 파일명만으로 처리해.
   - 캡처 파일이 없으면 ⑥은 "캡처 없음" 한 줄로 두고 넘어가.
     SVG 등으로 화면을 그려서 대신 채우지 마.
3. 브라우저로 한 번 열어 보여주고 끝낸다. 열어본 뒤 수정하지 마.

[포함할 내용]
① 프로젝트 제목과 작성자 이름 (맨 위에 크게)
② 만들려던 목표와 배경 (2~3문장)
③ 주요 기능 설명
④ 사용한 기술 (RAG·Tool Calling·MCP·Multi-Agent 중 해당 항목과,
  이 프로젝트의 어디에 쓰였는지)
⑤ 동작 시연 mock-up — 핵심 흐름 1개를 화면 3~5장으로, 버튼 클릭으로 넘기는 수준.
   데이터는 예시값을 하드코딩. 실제 앱 코드를 다시 읽거나 UI를 재현하지 마.
   JS 150줄 이내. 차트·애니메이션 없음. 어려우면 정적 화면.
⑥ 실행 결과 스크린샷 — 장면마다 한 줄 설명
⑦ (트랙 1·2) 라운드 기록 표 — 라운드 0부터의 통과 수와 고친 것
⑧ 실무 적용 시 필요한 것
   - 실제 업무에 쓰려면 어떤 데이터·시스템 연동이 필요한가
   - 그 데이터를 외부 AI 서비스에 넣어도 되는가

[조건]
- CSS·JS 전부 파일 안에. 외부 라이브러리·CDN·웹폰트·인터넷 요청 금지.
- CSS 80줄 이내. 단순한 문서 스타일. 디자인 시스템·다크모드 만들지 마.
- 이미지는 base64 인라인만.
```

### 확인할 것
- `report.html`을 브라우저로 열어 ①~⑧ 항목이 다 채워졌는지 확인
- **인터넷을 끊어도 열려야 함** — 외부 로드가 하나라도 있으면 제출 플랫폼에서 그 부분이 비어 보임
- mock-up이 잘 안 만들어지면 **정적 화면**으로 두고 넘어감 — 항목이 모두 채워진 게 더 중요

### 막히면
| 증상 | 해결 |
|---|---|
| 브라우저에서 안 열림 | "브라우저에서 오류가 나니 코드를 고쳐 다시 만들어줘" (결과 페이지 수정은 코드 확정 제한에 안 걸림) |
| 스크린샷 안 보임 | "이미지를 base64 로 인라인해줘. 외부 경로를 참조하지 마." |
| 파일이 너무 큼 | 캡처 2~3장으로 줄이거나 "이미지 폭을 1000px로 줄여서 다시 넣어줘" |
| mock-up 생성 반복 실패 | 정적 화면으로 고정하고 다음으로 진행 |

## 제출하기
로그인 → **[결과물 제출하기]** 또는 상단 메뉴 **[제출하기]**

양식:
- **작품명** — `앱 이름 - 본인 이름` 형식. **제목에 반드시 본인 이름 포함**
- **작품 설명** — 1~2줄
- **HTML 파일 업로드** — `report.html`
- **미리보기** — 업로드 후 아래에 표시됨. 스크린샷·mock-up이 보이는지 여기서 확인, 비면 위 표대로 재수정 후 재업로드
- **예시 데이터**(선택) — 사용한 가상 데이터 파일(CSV·JSON). 올리기 전 사내 정보 재확인

**[제출하기]** → 완료. **전시관**에서 동료 결과물 열람 가능 — 서로 페이지가 안 깨졌는지 확인.

> 시간이 촉박하면 **기한 내 제출 먼저**, 제출 후 남은 시간에 재수정·재업로드 가능.

### 막히면
- 업로드 안 됨 → 파일이 `.html` 단일 파일인지, 용량이 과한지 확인. 마감 임박 시 이미지 줄인 판이라도 먼저 제출
- 미리보기 비어있음 → 외부 라이브러리/인터넷 요청이 남아있는 경우. 조건대로 전부 파일 안에 인라인해서 재생성
