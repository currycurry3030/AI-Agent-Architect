# 8교시 · 캡스톤 2 — 쉬운 설명 버전

## 마지막 단계: 결과를 한 장짜리 페이지로 정리하기

제출은 **HTML 파일 하나**로만 받습니다. 압축파일도, 링크도 아니고 딱 그 파일 하나만 열면 전부 보여야 합니다. Claude Code에게 이렇게 시킵니다.

```
프로젝트가 완성됐어. 제출용 결과 페이지 report.html을 만들어줘.

[포함할 내용]
① 프로젝트 제목과 작성자 이름
② 만들려던 목표와 배경 (2~3문장)
③ 주요 기능 설명
④ 사용한 기술과, 이 프로젝트의 어디에 쓰였는지
⑤ 동작 시연 화면 3~5장 (버튼 클릭으로 넘기는 수준, 예시 데이터로)
⑥ 실행 결과 스크린샷
⑦ 실무에 쓰려면 뭐가 더 필요한지

[조건]
- 이미지와 스타일은 전부 파일 안에. 인터넷 연결 없이도 열려야 해.
```

포트폴리오 페이지 만드는 것과 똑같은 감각이에요 — **이 파일 하나로 무엇을 만들었는지 다 설명**되게 만드는 겁니다.

## 확인할 것

- 인터넷을 끊고 열어봐도 정상적으로 보이는지 (외부에서 뭔가 불러오고 있으면 그 부분이 비어 보입니다)
- ①~⑦ 항목이 다 채워졌는지

## 제출하기

정해진 제출 페이지에 가입하고, 작품명(본인 이름 포함)과 설명을 적은 뒤 `report.html`을 올립니다. 업로드 후 미리보기에서 이미지가 잘 보이는지 한 번 더 확인합니다.

## 오늘 만든 걸 계속 쓰려면

오늘 만든 프로그램들은 그대로 가져가서 계속 쓰실 수 있습니다. `.env` 안의 API 키는 개인에게 발급된 것이니 잘 보관해두세요.

## 정리

오늘 하루, 코드를 몰라도 프롬프트로 4개의 프로그램을 만들었습니다. Midjourney·Higgsfield로 이미지·영상을 만들던 것과 원리는 같습니다 — **원하는 걸 구체적으로 설명할수록, 원하는 결과가 나온다**는 것. 이제 그 감각을 텍스트/코드에도 적용할 수 있게 되신 거예요.
