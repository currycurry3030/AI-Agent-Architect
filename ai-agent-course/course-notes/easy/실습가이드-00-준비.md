# 자습·실습 가이드 — 준비 (쉬운 설명 버전)

이 가이드는 [학습노트(쉬운 설명)](../README.md)에서 배운 걸 **혼자서 순서대로 따라 할 수 있는 체크리스트**로 정리한 것입니다. 여기 나오는 프롬프트·명령어는 일반 버전과 완전히 똑같습니다 — 난이도는 "설명 방식"만 다르고, 실제로 하는 작업은 동일해야 하니까요.

## 원본 교육과 다른 점 (자습 시 꼭 확인)

원본은 회사에서 진행한 1일짜리 교육이라, 미리 나눠준 계정·파일·제출 사이트에 의존합니다. 혼자 하실 땐 아래처럼 바꿔서 진행합니다.

| 원본(교육) | 자습 대체 |
|---|---|
| 미리 나눠준 OpenAI API 키(=서비스 이용 인증서) | **본인 OpenAI API 키**를 직접 발급 (platform.openai.com → API keys). 결제수단 등록이 필요하고, 사용량 한도(Usage limits)를 낮게 걸어두면 안심됩니다 |
| 모델명 `gpt-5.6-luna` (교육 때만 쓰던 이름) | 본인 계정에서 **실제로 쓸 수 있는 최신 GPT 모델**로 대체. Midjourney 버전 고르듯, Claude Code에게 "지금 내 계정에서 쓸 수 있는 모델 목록을 확인해줘"라고 물어보면 됩니다 |
| 미리 만들어진 실습용 앱 파일 | **02·04 가이드에 들어있는 프롬프트**로 Claude Code가 그 앱을 처음부터 직접 만들어줍니다 (오히려 "말로 프로그램 만들기" 연습이 한 번 더 되는 셈) |
| 회사 전용 참고 문서 | 사내 자료라 나눠드릴 수 없어요 — **본인이 가진 PDF 3~5개**(회사 문서·매뉴얼·보고서 등, 표가 섞인 것일수록 좋음)로 대체 |
| 트랙2용 특정 공공 문서 | **실제로 존재하는 공개 자료라 그대로 받을 수 있어요**: [통계청 소비자물가동향](https://kostat.go.kr) 최신 호를 내려받아 사용 |
| 팀 제출 사이트 | 회사 행사 전용이라 자습에서는 **건너뜁니다** — 결과물은 개인 포트폴리오 파일로만 남깁니다 |
| 8교시 고정 시간표 | **원하는 속도로** — 한 단계당 45~90분 정도 예상하시면 됩니다. 하루에 몰아서 해도 되고 며칠에 나눠도 됩니다 |

## 환경 준비 체크리스트

- [ ] PowerShell(까만 화면)에서 Claude Code가 설치돼 있는지 확인
  ```powershell
  claude --version
  ```
  안 되면: `irm https://claude.ai/install.ps1 | iex` 실행 후 창을 닫았다가 새로 열기
- [ ] OpenAI API 키 발급 — https://platform.openai.com/api-keys 에서 `sk-...`로 시작하는 문자열(=인증서) 복사
- [ ] (선택, 5단계에서 필요) Tavily 무료 API 키 발급 — https://app.tavily.com (구글 계정으로 가입 가능)
- [ ] 실습용 폴더 만들기
  ```powershell
  mkdir C:\ai-agent-selfstudy
  cd C:\ai-agent-selfstudy
  ```
- [ ] 단계별 하위 폴더는 각 가이드에서 시키는 대로 그때그때 만들면 됩니다

## 진행 순서

```
00 준비 (지금 여기)
 └ 01 웹앱      → 02 RAG1 → 03 RAG2 (같은 폴더 이어서)
                → 04 ToolCalling → 05 MCP → 06 MultiAgent (같은 폴더 이어서)
                → 07 캡스톤 (자유 주제, 나만의 프로젝트)
```

01은 독립된 폴더에서 새로 시작, 02~03은 같은 `rag-lab` 폴더를 이어서, 04~06은 같은 `agent-lab` 폴더를 이어서 사용합니다. 07은 그중 하나를 골라 본인 주제로 확장합니다.

## 각 단계 진행하는 법 (공통)

1. 체크박스를 위에서부터 순서대로 실행합니다
2. 프롬프트로 코드를 바꾼 뒤에는 **서버(까만 실행 창)를 껐다 켜야** 반영됩니다 (`Ctrl+C`로 끄고 다시 실행)
3. 막히면 각 가이드 맨 아래 "막히면" 표를 먼저 확인, 그래도 안 풀리면 Claude Code에게 화면에 뜬 오류 메시지를 그대로 붙여넣고 물어보세요
4. 개념이 헷갈리면 같은 번호의 [학습노트(쉬운 설명)](../01-바이브코딩-웹앱.md)를 열어 비유로 다시 확인

준비가 끝났으면 [01-웹앱 실습 가이드](실습가이드-01-웹앱.md)로 이동하세요.
