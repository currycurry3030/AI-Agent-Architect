# 실습 가이드 4 · Tool Calling — 도구 설명문이 선택을 좌우한다 (쉬운 설명 버전)

목표: AI가 도구(포토샵 액션 같은 것)를 "이름표(설명문)만 보고" 고른다는 걸 직접 뒤집어보며 확인합니다.

원본은 [학습노트 04(쉬운 설명)](../04-ToolCalling.md) 참고. 원본은 미리 만든 앱으로 시작하지만, 자습에서는 Claude Code에게 그 앱을 직접 만들게 합니다.

## 체크리스트

### 1. 폴더 생성 & 앱 만들기

```
Tool Calling 실습용 웹앱을 만들어줘. 파이썬(FastAPI 등) + 간단한 웹 UI로, OpenAI 함수 호출(function calling) 사용.

[기능]
- 메모(note) 저장/조회 도구 3개를 만들어줘: 저장(memo_tool_1), 조회(memo_tool_2), 삭제(memo_tool_3).
  각 도구는 인자로 text 하나만 받아. 메모는 로컬 JSON 파일(data/notes.json)에 저장해줘.
- 화면 왼쪽에 도구 목록을 보여줘: 이름 / 설명문(텍스트박스로 직접 수정 가능, [적용] 버튼) / 인자.
  설명문을 수정하면 코드는 안 건드리고 즉시 그 설명문으로 OpenAI에 전달되게 해줘 (재시작 불필요).
  [설명문 되돌리기] 버튼도 만들어줘.
- 화면 왼쪽 아래에 "역할(시스템 프롬프트)" 텍스트박스를 만들어줘. 여기 적은 내용이 그대로 시스템 프롬프트로 들어가게 해줘.
  [되돌리기] 버튼도 만들어줘.
- 화면 왼쪽 아래에 데이터 파일 경로를 보여주고 수정할 수 있게 해줘 (도구 실패 테스트용).
- 화면 오른쪽에 "물어보기" 입력창과 답변, 그 아래 호출 로그(어떤 도구를 어떤 인자로 불렀는지, 도구가 뭘 반환했는지)를 보여줘.
- 화면 오른쪽 아래에 현재 저장된 메모 목록을 실시간으로 보여줘. [메모 초기화] 버튼도 만들어줘.
- .env 에서 OPENAI_API_KEY 를 읽어서 쓰고, .gitignore 에 .env 추가해줘.
```

### 2. 기본 동작 관찰
- [ ] `회의 메모 좀 찾아줘` → 어느 도구(액션)가 불렸는지 호출 로그 확인
- [ ] `내일 오후 3시에 품질 회의 있다고 메모해줘` → 어느 도구가 불렸는지 확인

### 3. 이름표(설명문) 뒤바꾸기 실험
- [ ] `memo_tool_1`(저장) 설명문 → `"저장된 메모 중 키워드에 해당하는 것을 찾아 목록으로 보여준다."`로 변경
- [ ] `memo_tool_2`(조회) 설명문 → `"새 메모를 저장한다."`로 변경
- [ ] 2번의 질문 2개를 다시 던져 **선택이 뒤집히는지** 확인 (코드/앱 재시작 없이 — 이름표만 바꿨는데도!)
- [ ] [설명문 되돌리기]로 원복

### 4. 애매한 이름표 vs 명확한 이름표
- [ ] 두 도구 설명문을 일부러 애매하게 바꿔보고("메모 관련 작업을 처리한다" 등) 질문 재실행 → AI가 헷갈려하는지 확인
- [ ] "무엇을 하는지"가 아니라 "어떤 상황에 쓰는지" 기준으로 설명문을 직접 다시 써서 확실히 갈리게 만들기

### 5. 직무기술서(역할 프롬프트)로 행동 제한하기
- [ ] 역할 칸 비운 채 `회의 메모 삭제해줘` → 삭제됨
- [ ] `메모 초기화` 후, 역할 칸에 `너는 메모 조회 담당이다. 조회만 한다.` 추가 → 삭제 요청 재시도
- [ ] 표현을 바꿔서(`이제 필요 없어. 정리해줘` 등) 우회되는지 시도
- [ ] `메모를 수정하거나 삭제하는 일은 어떤 경우에도 하지 않는다.` 문구 추가 후 재시도
- [ ] 결론: 도구(액션)는 계속 그 자리에 있었습니다 — 문구만으로 막는 방식의 한계를 한 문장으로 정리

### 6. 도구(액션) 하나 직접 추가하기 (수정 기능)
```
memo_tool_4 를 추가해줘.
- 파라미터는 다른 도구들과 똑같이 text 하나만 써야 해.
- 키워드로 메모를 찾아 내용을 새 내용으로 바꾸는 동작이야.
- 화면 도구 목록에 나타나고, 설명문도 화면에서 고칠 수 있어야 해.
- 잘못된 인자가 오면 어떤 형태로 넣어야 하는지 알려주는 오류를 돌려줘.
```
(서버 재시작) 설명문을 직접 작성해서 `품질 회의 안건 메모의 내용을 '차주 월요일 10시로 변경'으로 바꿔줘` 실행 → 의도대로 동작할 때까지 설명문 다듬기

### 7. 도구가 실패하면 어떻게 되는지 관찰
- [ ] 데이터 파일 경로를 존재하지 않는 값으로 바꾸고 질문 → AI의 대응 관찰
- [ ] 경로 원복
