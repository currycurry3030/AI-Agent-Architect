# 실습 가이드 7 · 캡스톤 — 나만의 프로젝트 (쉬운 설명 버전)

목표: 지금까지 배운 것 중 필요한 걸 조합해, 본인 주제로 실제 동작하는 결과물 하나를 완성합니다.

원본은 [학습노트 07](../07-캡스톤1-기획제작.md)·[08](../08-캡스톤2-완성제출.md) 참고. 자습에서는 **정해진 마감 시각과 회사 제출 절차가 없습니다** — 원하는 속도로 진행하고, 결과는 개인 포트폴리오로 남깁니다.

## 체크리스트

### 1. 주제 정하기
1~6단계에서 "이건 내 작업에도 쓰겠는데" 싶었던 순간이 있으면 그걸 붙잡습니다. 없으면 아래 중 하나를 고릅니다.

- [ ] **자유 주제** — 배운 걸 조합해 만들고 싶은 것
- [ ] **도구 설계형** — `agent-lab`을 본인 시나리오로 확장 (도구 3종 이상 + 질문 10개 중 8개 이상 정확히 처리되게)
- [ ] **문서 질답형** — `rag-lab`에 본인 문서를 저장하고, 함정 질문 5개를 스스로 만들어 4개 이상 통과시키기 (표 속 정답 / 비슷한 항목 혼동 / 조각 경계 / 이중 기준 / 지어내기 유도 — [학습노트 07의 예시](../07-캡스톤1-기획제작.md) 패턴 참고)
- [ ] **조사 리포트형** — `agent-lab`의 팀 구조(Multi-Agent)로 본인 주제 연구 리포트 만들기

### 2. 만들기 전 점검 (5~10분만)
새 폴더에서 Claude Code에게 먼저 물어봅니다.
```powershell
mkdir C:\ai-agent-selfstudy\07-capstone
cd C:\ai-agent-selfstudy\07-capstone
claude
```
```
내 프로젝트 주제를 알려줄게. 만들기 전에 아래를 점검해줘.

주제: [한 줄]
만들고 싶은 것: [화면 기준으로 구체적으로]

① 범위 — 몇 시간 안에 혼자 만들 수 있는 크기인가? 너무 크면 어디를 잘라야 하는지 알려줘.
② 기술 매핑 — RAG·Tool Calling·MCP·Multi-Agent 중 무엇을 쓰게 되나?
③ 데이터 — 어떤 데이터가 필요하고, 없는 건 가상으로 만들어줄 수 있나?
④ 입력 점검 — 내 설명에 민감한 정보(회사 기밀, 개인정보 등)가 섞여 있으면 짚어주고 가상 버전으로 제안해줘.
```

디자인 작업으로 치면 "이 컨셉, 오늘 안에 완성 가능한 볼륨일까요?"를 미리 물어보는 것과 같습니다.

- [ ] 제안받은 범위를 그 자리에서 확정 (이 단계에 너무 오래 쓰지 않기)
- [ ] 민감 정보가 지적되면 가상 데이터로 교체

### 3. 만들기
- [ ] 시작할 앱(01/02/04 중 관련된 것)을 이 폴더로 복사해서 작업 (원본은 그대로 둠)
- [ ] 먼저 **끝까지 도는 최소 버전**부터 완성 (완성도보다 정상 동작이 먼저)
- [ ] 남는 시간에 기능 추가
- [ ] 문서/도구 챌린지형이라면: 손대기 전 **라운드 0**(기준선) 먼저 측정 → 한 번에 한 가지씩 고치며 라운드 기록
  ```
  라운드 0 (기준선): 통과 ___/___
  라운드 1 (처방: ______): 통과 ___/___
  ```

### 4. 결과 페이지 만들기 (선택이지만 권장 — 포트폴리오용)
```
프로젝트가 완성됐어. 결과 페이지 report.html을 만들어줘.

[포함할 내용]
① 프로젝트 제목과 목표/배경 (2~3문장)
② 주요 기능 설명
③ 사용한 기술 (RAG·Tool Calling·MCP·Multi-Agent 중 해당 항목과 어디에 쓰였는지)
④ 동작 시연 mock-up — 핵심 흐름 1개를 화면 3~5장으로, 버튼 클릭으로 넘기는 수준. 데이터는 예시값 하드코딩.
⑤ 실행 결과 스크린샷 (있으면)
⑥ (챌린지형이라면) 라운드 기록 표
⑦ 실무 적용 시 필요한 것 — 어떤 데이터·시스템 연동이 필요한가, 그 데이터를 외부 AI 서비스에 넣어도 되는가

[조건]
- CSS·JS 전부 파일 안에. 외부 라이브러리·CDN·인터넷 요청 금지 (인터넷 없이도 열려야 함).
- 이미지는 base64 인라인만.
```
- [ ] `report.html`을 인터넷 끊고 열어봐서 정상 표시되는지 확인
- [ ] 원하면 GitHub Pages, Notion 파일 첨부 등 원하는 곳에 개인적으로 보관/공유

> 원본 8교시의 "제출 사이트 가입·제출" 부분은 회사 행사 전용이라 자습에서는 생략합니다. `report.html`은 그 자체로 완결된 포트폴리오 파일입니다.
