# 1교시 · 웹앱 만들기 — 쉬운 설명 버전

## 오늘 처음 하는 것: 말로 프로그램 만들기

Midjourney나 Higgsfield에 프롬프트를 넣으면 이미지·영상이 나오죠. 오늘 쓰는 **Claude Code**도 똑같은 방식인데, 결과물이 그림이 아니라 **진짜로 동작하는 프로그램**이라는 게 다릅니다. "지도랑 날씨 보여주는 앱 만들어줘"라고 말하면, 실제로 클릭하면 동작하는 웹페이지가 만들어집니다.

이걸 "바이브코딩"이라고 부릅니다. 코드 문법을 몰라도, 원하는 결과를 문장으로 설명할 수 있으면 만들 수 있습니다.

## 왜 하필 터미널(까만 화면)에서 하나

Claude Code는 브라우저가 아니라 PowerShell이라는 까만 화면(터미널)에서 씁니다. 어색해 보이지만 이유가 있어요 — **AI가 지금 폴더 안에 뭐가 있는지 다 보고, 파일을 직접 만들고 고치기 때문**입니다. 포토샵 액션이 레이어 패널을 직접 조작하듯, Claude Code는 폴더 안의 파일을 직접 조작합니다. 대신 파일을 만들거나 지우기 전엔 항상 "이거 해도 될까요?"라고 먼저 물어봅니다.

## API란? — "정해진 형식으로 주문하면 정해진 형식으로 답을 주는 창구"

스톡 이미지 사이트에서 "sunset"이라고 검색하면 관련 사진들이 쫙 나오죠. API도 비슷합니다. 정해진 주소에 정해진 형식으로 "이 위치의 날씨 알려줘"라고 요청하면, 정해진 형식으로 숫자(기온 등)가 돌아옵니다. 오늘 쓰는 두 창구:

- **Leaflet** — 지도를 그려주고, 클릭한 위치의 좌표를 알려주는 창구
- **Open-Meteo** — 좌표를 주면 날씨를 알려주는 창구 (회원가입 필요 없음)

## API 키와 보안 — "내 이름으로 쓸 수 있는 인증서"

날씨 창구는 회원가입이 필요 없지만, 이따 붙일 **AI 챗봇 기능(OpenAI GPT)**은 다릅니다. AI를 한 번 부를 때마다 실제 비용이 들기 때문에, "누가 부르는지" 확인하는 인증서가 필요합니다. 이게 **API 키**예요.

> ⚠️ 이 키를 가진 사람은 누구나 내 이름으로 요금을 쓸 수 있습니다. 그래서 코드 안에 직접 적지 않고, `.env`라는 별도 서랍(파일)에 따로 보관합니다. 이 서랍은 **다른 사람과 공유되는 저장소(Git)에 실수로 올라가는 걸 막아주는 용도**입니다 — Claude Code 본인은 이 서랍을 열어볼 수 있다는 점은 알아두세요 (오늘 실습에선 문제 없지만, 회사 업무에 쓸 땐 이 부분을 더 신경 써야 합니다).

## 실습 1 — 지도 날씨 앱 만들기

Claude Code 입력창에 이렇게 프롬프트를 넣습니다 (Midjourney 프롬프트 넣는 것과 똑같은 감각이에요):

```
지도에서 위치를 클릭하면 그 지역의 현재 날씨와 앞으로 7일 예보를 보여주는
웹 앱을 만들어줘.
지도는 Leaflet을 쓰고, 날씨 데이터는 Open-Meteo API를 써줘.
다 만들면 브라우저에서 열어서 보여줘.
```

**"무엇으로 만들지" 지정한 이유**: Leaflet, Open-Meteo처럼 이름을 콕 집어주지 않으면 AI가 알아서 고르는데, 그러면 매번 다른 재료로 만들어집니다. 포토샵으로 치면 "빈티지 느낌으로"보다 "필름 그레인 필터 + 세피아 톤"처럼 구체적으로 말할수록 원하는 결과가 나오는 것과 같습니다.

## 실습 2 — AI 챗봇 기능 추가하기

여기서부터가 오늘 배우는 두 번째 AI(OpenAI GPT)가 처음 등장하는 순간입니다. "오늘 우산 필요해?"라고 물으면 지금 보고 있는 지역의 날씨를 근거로 답해주는 챗봇을 붙입니다.

```
.env 의 OPENAI_API_KEY 를 환경변수로 읽어서 쓰고,
지금 보고 있는 지역의 날씨 데이터를 바탕으로
"오늘 우산 필요해?" 같은 질문에 답해주는 채팅창을 웹 앱에 추가해 줘.
키 값은 코드에 직접 쓰지 마.
```

**모델**은 본인 계정에서 실제로 쓸 수 있는 것으로 지정합니다. Midjourney에서 v5냐 v6냐 고르는 것과 같은 선택이라고 생각하시면 됩니다 — 버전마다 성능·속도·비용이 다릅니다.

## 정리

- 오늘 한 일 = **프롬프트로 결과물을 주문하는 것**. Midjourney에서 하던 것과 똑같은 감각이지만, 결과물이 이미지 대신 "동작하는 프로그램"인 것뿐입니다.
- API 키는 로그인 비밀번호처럼 다루기 — 코드에 직접 적지 말고 `.env` 서랍에.
- 다음 시간 질문: *이 AI가 우리 회사 문서 내용도 알고 있을까?* → 답은 "아니요, 대신 찾아서 보여주는 방법이 있다"입니다. 다음 시간에 그걸 배웁니다.
