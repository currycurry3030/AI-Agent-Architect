# 실습 가이드 1 · 웹앱 만들기 (지도+날씨+AI 채팅)

목표: Claude Code로 코드 한 줄 안 쓰고 동작하는 웹앱 하나를 완성하고, `.env`로 API 키를 안전하게 다루는 습관을 들인다.

원본은 [학습노트 01](01-바이브코딩-웹앱.md) 참고 — 자습 시 배부 계정 대신 본인 키를 씁니다.

## 체크리스트

- [ ] 폴더 생성 및 진입
  ```powershell
  mkdir C:\ai-agent-selfstudy\01-webapp
  cd C:\ai-agent-selfstudy\01-webapp
  claude
  ```
- [ ] 웹앱 만들기 지시
  ```
  지도에서 위치를 클릭하면 그 지역의 현재 날씨와 앞으로 7일 예보를 보여주는
  웹 앱을 만들어줘.
  지도는 Leaflet을 쓰고, 날씨 데이터는 Open-Meteo API를 써줘.
  다 만들면 브라우저에서 열어서 보여줘.
  ```
- [ ] 브라우저에서 지도를 클릭해 날씨가 실제로 뜨는지 확인
- [ ] `.env` 생성 (값은 비워서 만들게 한 뒤 직접 채움)
  ```
  이 폴더에 .env 파일을 만들고 OPENAI_API_KEY 항목을 넣어줘.
  값은 비워 두고, 내가 직접 채울게.
  그리고 .gitignore 에 .env 를 추가해줘.
  ```
- [ ] 메모장으로 `.env` 열어 `OPENAI_API_KEY=` 뒤에 본인 키(`sk-...`) 붙여넣고 저장
  - 파일명이 `.env.txt`로 저장되지 않았는지 확인 (탐색기에서 확장자 표시 켜기)
- [ ] 채팅 기능 추가 (모델명은 본인 계정에서 실제 쓸 수 있는 것으로 — 예: `gpt-4o-mini`, `gpt-4.1` 등. 확실하지 않으면 Claude Code에게 "내 OpenAI 계정에서 사용 가능한 모델 목록을 확인해줘"라고 먼저 물어보기)
  ```
  .env 의 OPENAI_API_KEY 를 환경변수로 읽어서 쓰고,
  지금 보고 있는 지역의 날씨 데이터를 바탕으로
  "오늘 우산 필요해?" 같은 질문에 답해주는 채팅창을 웹 앱에 추가해 줘.
  키 값은 코드에 직접 쓰지 마.
  ```
- [ ] 채팅창에 "오늘 우산 필요해?" 입력 → 답변이 지금 선택한 지역의 실제 데이터를 근거로 하는지 확인
- [ ] (선택) 개선 지시 하나 던져보기 — 걸린 시간을 재보며 "만드는 시간 vs 고치는 시간" 감각 익히기
  ```
  예보를 표로 말고 그래프로 보여줘.
  ```

## 완료 기준
- [ ] 지도 클릭 → 날씨/예보 표시됨
- [ ] 채팅에 날씨 관련 질문 → 실제 데이터 근거로 답변
- [ ] `.env`에 키가 있고, 코드 안에는 키가 직접 적혀있지 않음 (Claude Code에게 "코드에 API 키가 하드코딩된 곳이 있는지 확인해줘"로 재확인 권장)

## 막히면
| 증상 | 해결 |
|---|---|
| 지도가 회색 | 브라우저 새로고침 |
| 채팅에서 401/키 오류 | `.env` 파일명·키 값 재확인 |
| 요청이 너무 자주 막힘(rate limit) | OpenAI 대시보드에서 사용량 한도 확인 |
