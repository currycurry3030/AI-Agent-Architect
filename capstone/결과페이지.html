트랙 1 · 도구 설계 · Process Detective

AI Process Trouble Shooting Agent

LLM 이 공정 원인을 추측하는 것이 아니라, LLM 이 필요한 분석 도구를 선택하고 실제 데이터 분석 결과를 근거로 원인 후보를 정리합니다.

1. 문제 정의

공정 데이터에 이상이 발생하면 분석 담당자가 기간 비교, 변수 변화 확인, 이상치 탐색, 장비별 비교, 영향 변수 분석을 매번 각각 수행해야 합니다. 분석 목적에 맞는 방법과 코드를 직접 골라야 하므로 초기 조사에 반복 작업이 많습니다.

사용자가 자연어로 이상 현상을 질문하면, Agent 가 질문의 분석 의도를 판단해 적절한 Python 분석 도구를 선택·실행하고, 여러 도구 결과를 종합해 데이터상 근거가 있는 원인 후보와 추가 확인 항목을 제시합니다.

포함하지 않는 것: 실제 원인의 자동 확정, 실제 생산 데이터 연결, 복잡한 causal inference, 불필요한 Multi-Agent 구조.
