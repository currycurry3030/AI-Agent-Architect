AI Process Trouble Shooting Agent - 도구 기반 공정 이상 원인 분석 에이전트

작성자: 박병준 · 트랙 1 · 도구 설계 · 2026-09-03

① 프로젝트 개요

AI Process Trouble Shooting Agent 는 반도체 공정 데이터를 다루는 Tool Calling 기반 AI Agent 입니다. 사용자가 자연어로 이상 현상을 질문하면 4개의 Python 분석 도구 중 필요한 것을 스스로 선택·실행해 실제 계산 결과를 근거로 원인 후보를 정리합니다.

② 목표와 배경

공정 데이터에 이상이 생기면 공정엔지니어가 기간 비교·이상치 탐색·변수 순위·추이 확인을 매번 손으로 반복해야 합니다. 이 프로젝트는 사용자가 자연어로 질문하면 LLM이 원인을 임의로 추측하는 대신 실제 Python 분석 도구를 선택·실행하고, 그 결과값을 근거로 원인 후보를 정리하는 Agent를 만드는 것을 목표로 했습니다.

③ 주요 기능

  • 자연어 질문의 분석 의도를 판단해 적절한 도구를 자동 선택·연쇄 호출
  • 도구가 실제로 계산한 값만 근거로 사용 (수치 지어내기 금지)
  • 실제 데이터 분석이 필요한 질문에는 결과를 분석 요약 → 원인 후보(High/Medium/Low) → 해석 주의사항 → 추가 확인 항목 순으로 정리 (존재하지 않는 장비 등 도구로 답할 수 없는 질문에는 이 틀 대신 짧게 답변)
  • 화면에서 도구 설명문·시스템 프롬프트를 직접 수정하고 재평가 가능
도구역할
compare_period두 기간의 변수 평균 비교 (인자 비우면 최근 7일 vs 그 이전 전체 자동 비교)
find_outliersequipment/lot_id/wafer_id 기준으로 이상 그룹 탐색
rank_featurestarget(기본 yield)과 상관관계 큰 변수 순위
plot_trend변수의 일별 추이 + 기준 대비 이탈 시작일 자동 판정

⑤ 동작 시연 mock-up

1. 질문 입력

"최근 품질 지표가 나빠진 원인을 분석해줘."

[분석 실행] 버튼을 누르면 Agent가 도구 선택을 시작합니다.

2. 도구 호출

호출된 도구 (3회, 8.2초)

compare_period() rank_features(target=yield) find_outliers(by=equipment)

3. 분석 요약

수율 95.37% → 90.10% (5.27%p 하락)
가장 크게 변한 변수: Pressure 101.6 → 111.9 (+10.15%)
결함률 1.83% → 4.03% (+120.64%)

4. 원인 후보

High 결함률 증가 (상관계수 -0.962)

High Pressure 상승 (상관계수 -0.864)

Medium EQP_Y 편중 (결함률 2.86% vs EQP_X 1.83%)

5. 해석 주의사항

상관관계와 동시 변화만으로는 인과관계를 확정할 수 없습니다. 레시피·정비 이력 대조가 추가로 필요합니다.

⑧ 실무 적용 시 필요한 것

  • 필요한 데이터·시스템 연동: 실제 MES/이력 시스템의 공정 로그(설비·LOT·wafer 단위 센서값), 레시피 변경 이력, 설비 정비 이력 DB 연동이 필요합니다. 현재는 가상 CSV로만 검증했습니다.
  • 외부 AI 서비스 반입 가능 여부: 원시 공정 데이터를 그대로 외부 LLM API에 보내는 것은 지양해야 합니다. 사내 프록시·마스킹(장비·LOT 식별자 익명화)을 거치거나 사내 폐쇄망 LLM으로 전환하는 검토가 먼저 필요합니다.
